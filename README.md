# Bolta Bazaar 🛒🎙️

**Bolta Bazaar** is a mobile-first, voice-driven inventory management web application tailored specifically for Pakistani shopkeepers. 

## 🎯 Goal
To minimize typing and streamline shop management. Shopkeepers can simply record Urdu (or Roman Urdu) voice notes to log inventory, update stock, and track sales. 

## 🛠️ Tech Stack
- **Frontend**: React (Vite) + Tailwind CSS
- **Backend**: FastAPI (Python)
- **AI/Voice Processing**: Gemini 1.5 Pro
- **Design System**: Mobile-first, following Google Material Design principles with Telenor 4G brand colors (Blue, White, Red).

## 🚀 Features (Planned)
- **Voice-to-Text Inventory**: Speak in Urdu to add items to stock.
- **Smart Parsing**: Uses Gemini 1.5 Pro to extract item names, quantities, and prices from voice notes.
- **Mobile-Optimized Dashboard**: Clean, vibrant, and intuitive interface designed for quick interactions on mobile devices.

## 🎨 Visual Style
- **Primary Color**: Telenor Blue
- **Accent Colors**: White & Red
- **Aesthetics**: Clean, modern, high-contrast for readability, and dynamic micro-animations to enhance the user experience.
